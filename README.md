# diecast_garage

Project Description
My Diecast Garage

My Diecast Garage is a personal diecast collection management app designed for collectors who want a clean and organized way to track their collection.

The app helps users manage diecast models from brands like Hot Wheels, Matchbox, Mini GT, Inno64, Tarmac Works, AutoArt, and other premium diecast manufacturers.

Built with a collector-first approach, the app focuses on inventory tracking, collection organization, duplicate prevention, wishlist management, and detailed collection statistics — without social media or marketplace distractions.

Users can:

Add and manage diecast models
Store photos and collection details
Track purchase history and collection value
Organize models by brand, series, scale, or storage location
Quickly search and filter collections
Prevent accidental duplicate purchases
Maintain a personal wishlist
View collection insights and statistics

The app is designed as an offline-first experience to ensure fast performance and easy access anywhere, including during diecast hunts and store visits.

With a premium garage-inspired UI and smooth collector-focused workflows, My Diecast Garage aims to become a personal digital garage for diecast enthusiasts.
